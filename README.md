# Exam_score-Prediction
# 🎯 Exam Scores Prediction

This project uses machine learning to predict students' exam scores based on demographic and academic features. It demonstrates how data analysis and predictive modeling can uncover key factors influencing academic performance.

## 🧠 Project Description

The notebook explores a dataset containing students' performance in math, reading, and writing, along with features like:
- Gender
- Parental level of education
- Lunch type (standard or free/reduced)
- Test preparation course completion

The goal is to use this information to **predict exam scores**, understand **which factors influence performance**, and build models that can assist in **early intervention and academic planning**.

## 🚀 What You’ll Learn

- How to clean and preprocess real-world data
- How to perform exploratory data analysis (EDA)
- How to build regression models (Linear, Tree-based)
- How to evaluate model performance (MAE, MSE, R²)
- How to interpret predictions and visualize insights

## 🛠️ Tools Used

- Python 🐍
- Jupyter Notebook
- pandas, NumPy
- seaborn, matplotlib
- scikit-learn

## 📊 Dataset

The dataset includes:
- Categorical features like gender, lunch type, and test prep
- Numerical target variables: math, reading, and writing score
